# 陪伴学习层级导航一期方案

## 背景

当前陪伴学习页主要围绕知识点展开，用户可以看到知识地图和知识点进度，但缺少“科目 / 年级 / 章节 / 知识点”的上层语境。进入具体学习页后，学习记录和白板已经按 `kp_id` 隔离，但用户在导航层面仍不容易判断自己处在整门课程的哪个章节、当前章节完成了多少、下一步该学什么。

## 目标

一期先补齐学习导航的层级感，不重做课程体系：

- 在陪伴学习页展示当前课程路径：科目、年级、课程、章节。
- 将知识地图从单一知识点视图升级为“章节分组 + 知识点地图”的组合视图。
- 支持按章节筛选知识点，进入知识点时继续沿用现有 `kp_id` 学习隔离机制。
- 后端课程接口返回章节元数据，避免前端硬编码章节名称。

## 数据层级

一期采用以下层级：

```text
科目 subject
  年级 grade
    课程 course
      章节 chapter
        知识点 knowledge_point
          学习会话 session / 白板快照 whiteboard_snapshot
```

当前 `Course` 已有 `subject`、`grade`、`knowledge_points`；`KnowledgePoint` 领域模型已有 `chapter_id`。一期需要把这些字段通过课程接口透出：

- `CourseResponse.chapters`
- `KnowledgePointResponse.chapter_id`

## 交互设计

### 1. 顶部学习路径

在陪伴学习页头部增加一行路径信息：

```text
数学 / 初二 / 一次函数 / 当前章节
```

当前章节随章节筛选变化；未筛选时展示“全部章节”。

### 2. 章节概览

在整体进度下方加入章节条：

- 每个章节显示章节名、掌握数 / 总数、完成率。
- 当前章节高亮。
- “全部章节”作为默认入口。

### 3. 知识地图筛选

点击章节后：

- 概览数据仍显示整门课程进度。
- 知识地图只显示该章节内知识点。
- 继续学习按钮优先进入当前章节内的进行中/未完成知识点。

### 4. 兼容策略

如果历史数据没有 `chapter_id`：

- 前端归入“未分章”分组。
- 知识地图仍可用，不阻塞学习。

## 非目标

一期不做以下内容：

- 不新增多科目切换页。
- 不重构课程管理后台。
- 不改变现有学习流、评估流和白板渲染逻辑。
- 不改变 `session` 与 `kp_id` 的隔离规则。

## 验收标准

- 课程接口返回章节和知识点所属章节。
- 陪伴学习页能看到科目、年级、课程、章节路径。
- 可以按章节筛选知识地图。
- 从章节内知识点进入学习页时仍携带正确 `kp_id`。
- 前端构建通过，后端相关文件语法检查通过。
